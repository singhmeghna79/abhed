The thesis

7.80× harness > model variance

The scaffold around the model decides more than the model does. A controlled study on SWE-bench Verified found harness-induced variance exceeds model-induced variance by 7.80×, reversing the ranking in 6 of 9 model-pair comparisons.

Change the scaffold — the context management, the tool contracts, the permission model — and the same model becomes a different product. Most of the industry treats that layer as glue code around someone else's API. Zybuu treats it as the product: engineered separately, evaluated separately, behind a provider abstraction.

Better model, better system. Better harness, better system. Both compound.
